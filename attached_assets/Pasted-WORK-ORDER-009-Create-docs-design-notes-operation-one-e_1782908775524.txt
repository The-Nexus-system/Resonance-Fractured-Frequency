# Operation One: Exodus

# Character Schedule

## Purpose

This document defines the ordinary lives of the people aboard CSV Hearth.

The Master Timeline answers:

"What happened?"

This document answers:

"Where is everyone when it happens?"

Every playable campaign references this document before creating scenes.

If a campaign conflicts with this schedule, this document is canon.

---

# Canon Rules

## Canon Rule

Characters continue living their lives when the player is somewhere else.

No character waits for the player.
 Everyone has responsibilities independent of gameplay.

---

## Canon Rule

Professional responsibilities always come before plot convenience.

Characters feel like real crew members rather than quest givers.

---

## Canon Rule

Every recurring character has a complete daily routine.

Wake.

Meals.

Work.

Breaks.

Community.

Sleep.

Routine creates personality.

---

## Canon Rule

Every recurring character should naturally appear in multiple campaigns.

No appearance should feel forced.

Crossovers happen because people work together.

---

## Canon Rule

Characters should become recognizable by routine.

The player should eventually know where someone probably is without opening a map.

---
