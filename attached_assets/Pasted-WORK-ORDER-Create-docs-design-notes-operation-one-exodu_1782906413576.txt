# Operation One: Exodus

# Character Schedule

## Purpose

This document defines the normal daily routines, duty schedules, locations and crossover opportunities for every major recurring character aboard CSV Hearth.

This document exists to ensure that every playable campaign remains chronologically consistent.

If two campaigns depict the same moment, every character should already have a defined location and responsibility.

---

# Canon Rule

Characters continue living their lives even when the player is not controlling them.

The player experiences one perspective.

The world continues everywhere else.

---

# Canon Rule

Characters must never exist in two places simultaneously.

Every appearance should be consistent with this schedule unless interrupted by story events.

---

# Canon Rule

Professional responsibilities come before gameplay convenience.

Characters should always feel like real crew members doing real jobs.

---
