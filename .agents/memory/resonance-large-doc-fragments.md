---
name: Resonance large-doc fragment strategy
description: How to reliably produce very large Resonance design docs without subagent timeouts.
---

Large Resonance design docs (e.g. modular_architecture_bible.md with 66 room modules, or the 12-character operation_one_exodus_character_schedule.md) cannot be produced by a single subagent — one full-file subagent repeatedly times out at the 300s StartToClose limit, often writing zero lines before dying.

**Rule:** for any doc that will exceed ~600 lines, split it. The main agent writes the H1, front matter, and end matter directly via bash heredoc; the body is generated by multiple parallel subagents, each writing ONLY its assigned sections (no H1, no front matter) to a temp fragment file (e.g. `docs/design_notes/_frag_*.md`). Then cat the fragments in order between the front and end matter, validate, and delete the temp files.

**Why:** a single subagent producing ~2000+ lines never finishes in 300s; ~11 room modules or one character section (~90–500 lines) finishes comfortably. Parallel fragments also run concurrently, so wall-clock stays low.

**How to apply:**
- Give every fragment subagent the SAME template + house-style + canon block so output is consistent, plus the exact ordered list of sections it owns and its output path.
- Include Attack-Day canon inline (GQ 06:35 by Naomi, 06:30 announcement, 06:32 anomaly, separate-pod scatter, Faience absent until damaged pod) so no fragment contradicts the timeline; tell them NOT to claim their character is strictly "last to launch" (Mara Chen and the Vale System body hold that).
- After assembly always run: `grep -c '^# '`=1, `grep -c '^|'`=0, `grep -cE '^\*\*[^*]+\*\*:?[[:space:]]*$'`=0, `grep '^#' f|sort|uniq -d`=empty, and confirm every required section/room is present.
- **Watch completeness:** a full-file subagent that "passes all structural checks" can still be missing whole sections (the character schedule initially had only 6 of 12 characters yet passed H1/table/dup checks). Always count expected sections against the required list, and let architect catch omissions.
