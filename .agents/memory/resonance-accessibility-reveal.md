# Shawabti accessibility reveal is gradual, not a single reveal

The player must NOT learn in one reveal that Shawabti civilization was built around accessibility / human diversity. That understanding unfolds gradually across Chapters Five, Six, and Seven.

In Chapter Five specifically, the player should only realize "this place seems to work for everyone" WITHOUT understanding why. The deeper conclusion (accessibility was assumed, the Shawabti built civilization around human diversity long before humanity existed) is deferred to later chapters.

**Why:** the user gave this as an explicit design adjustment while reviewing Work Order 005, to preserve mystery and give Ch5–7 room to unfold. When source Work Order text stated the conclusion outright (Ch5 Part Three and Part Six), it was softened to defer the "why" while keeping the principle "the game never directly explains this conclusion; players arrive at it naturally through repeated experience."

**How to apply:** when writing Ch6/Ch7 (or editing Ch5), keep observational statements ("works for everyone", "every method treated as equally valid") but do not state the causal explanation as a realization the player reaches until the later chapters build to it. Never let the game directly explain the conclusion.
