# Future Game Use — shared creative production reference

These reusable profiles are *franchise assets*, not a separate game and not a second authority for canon.

- **Six playable character wardrobe references:** `characters/nia-viaraxen.md`, `characters/kesh-rennik.md`, `characters/sanaa-al-khatib.md`, `characters/ilyan-ibarra.md`, `characters/mara-venn.md`, `characters/quillaan-folren.md`.
- **Reusable module principles:** see `wardrobe_visual_system.md`.
- **Resonance project working copies:** `docs/design_notes/character_wardrobe/`. The project copies preserve story/scene context.
- **True locked canon:** `docs/design_notes/first_fracture_episode_one_locked_rules.md` and protected bibles always outrank concept art notes.
- **Real assets and licensing:** `assets/REGISTRY.json`; the registry, not duplicated handoff prose, identifies actual sound, model, texture and animation file IDs.

**For next levels:** load the chosen character's profile, reapply reusable garment/material/equipment building blocks, review additions against current canon, connect only the new level's approved actions. Keep character-recognition layering stable unless character growth justifies a documented change.

**For other future games:** reuse the generic garment systems and source/licence facts without importing Resonance-specific characters, story, voices, ranks or mystery details by default.

**Status warning:** these are design concepts, not finished production assets. A character profile does not by itself prove audio wiring, a visual mesh, or playtesting.
